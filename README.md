# HRMS Admin Web (Frontend)

Repository for hosting the frontend code for HRMS admin web interface.

Built with React, TypeScript, Vite, Redux Toolkit, and SCSS modules.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
